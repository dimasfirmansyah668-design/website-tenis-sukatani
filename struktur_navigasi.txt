1. PENJELASAN UMUM & PETA RUTE SISTEM (SYSTEM ROUTING MAP)
----------------------------------------------------------------------------------
Struktur navigasi website Sistem Penyewaan Lapangan Tenis Sukatani dirancang dengan
arsitektur **Navigasi Hirarki Komposisi (Hybrid Navigation Architecture)** 3 tingkat:
- **Level 1 (Akses Utama)** : Halaman Login & Halaman Publik/Landing Page.
- **Level 2 (Menu Utama)**  : Menu Navigasi Utama pada Navbar/Sidebar.
- **Level 3 (Sub-Menu/Aksi)**: Modal Form, Aksi CRUD, Validasi, & Filter Data.

Setiap komponen menu dihubungkan menggunakan **panah dua arah (bidirectional arrow <--->)**
yang menggambarkan bahwa pengguna dapat berpindah antar-halaman utama dan fitur aksi
secara dinamis tanpa kehilangan konteks sesi pengguna.

Mapping Rute URL Website:
+-------------------+--------------------+---------------------------------------+
| Modul / Peran     | Route Path         | Komponen Halaman / Fitur              |
+-------------------+--------------------+---------------------------------------+
| Publik / Guest    | /                  | InformasiPage (Landing & Info Kontak) |
| Publik / Guest    | /informasi         | InformasiPage (Fasilitas & Jam Buka)  |
| Autentikasi       | /login             | LoginPage (Login User & Admin)        |
| Autentikasi       | /register          | RegisterPage (Pendaftaran User Baru)  |
| Pelanggan (User)  | /dashboard         | UserDashboard (Panduan & Alur)        |
| Pelanggan (User)  | /lapangan          | LapanganList (Katalog Arena Tenis)    |

| Admin (Pengelola) | /admin/pemesanan   | KelolaPemesanan (Validasi & Status)   |

| Admin (Pengelola) | /admin/laporan     | LaporanPage (Rekapitulasi & Cetak PDF)|
+-------------------+--------------------+---------------------------------------+

PENJELASAN STRUKTUR NAVIGASI ADMIN (Gambar 3.14):
      Struktur Navigasi Admin Gambar 3.14 terdapat susunan menu dan halaman yang dirancang untuk memudahkan pengelola dalam mengontrol dan mengoperasikan sistem. Di dalamnya, admin terlebih dahulu harus melakukan login untuk dapat masuk ke panel dashboard utama. Admin yang sudah melakukan login bisa mengakses menu dashboard admin, kelola pemesanan, kelola lapangan, kelola jadwal, kelola user, dan laporan transaksi. Pada menu kelola pemesanan admin dapat melihat detail pesanan, memvalidasi bukti pembayaran, serta mengonfirmasi atau membatalkan pesanan. Pada menu kelola lapangan admin dapat menambah lapangan, mengedit data lapangan, dan menghapus lapangan. Pada menu kelola jadwal admin dapat menambah slot blokir dan menghapus slot blokir untuk perawatan lapangan. Pada menu kelola user admin dapat mengubah status keaktifan user dan menghapus akun user. Pada menu laporan transaksi admin dapat memilih filter periode bulan dan mencetak laporan pendapatan.

PENJELASAN STRUKTUR NAVIGASI PELANGGAN (Gambar 3.15):
      Struktur Navigasi Pelanggan Gambar 3.15 terdapat susunan menu dan halaman yang dibuat untuk memudahkan pelanggan saat menggunakan sistem. Di dalamnya, pelanggan ketika belum login bisa mengakses beranda (informasi) dan daftar lapangan. Kalau melakukan pemesanan lapangan dengan mengklik booking sekarang harus login terlebih dahulu dan pengunggahan bukti pembayaran juga harus login terlebih dahulu. Pelanggan yang sudah melakukan login bisa mengakses dashboard pelanggan, daftar lapangan, form booking, riwayat booking, dan informasi kontak. Pada bagian daftar lapangan menampilkan detail lapangan dan direct booking. Bagian form booking menampilkan pilihan jadwal dan jam main serta konfirmasi booking. Bagian riwayat booking menampilkan detail booking ticket, upload bukti bayar, dan fitur kirim WhatsApp ke admin.

4. ALUR PROSES PENGGUNAAN SISTEM SECARA DETIL (SCENARIO FLOW)
----------------------------------------------------------------------------------

A. ALUR SCENARIO PELANGGAN (CUSTOMER USER JOURNEY):
1. **Pengaksesan Halaman Utama**: Pelanggan membuka URL website (`/`). Sistem menampilkan halaman `InformasiPage` berisi profil Sukatani Tenis.
2. **Registrasi / Login**:
   - Jika belum memiliki akun, pelanggan mengklik menu **Daftar** (`/register`) dan mengisi Nama, Email, No HP, serta Password.
   - Pelanggan melakukan login pada halaman `/login`. Sesi JWT token disimpan dan pelanggan diarahkan ke `/dashboard`.
3. **Eksplorasi Lapangan**:
   - Pelanggan membuka menu **Lapangan** (`/lapangan`) untuk melihat katalog.
   - Pelanggan mengklik tombol **Detail** untuk melihat foto dan fasilitas.
   - Pelanggan mengklik **Pesan Sekarang**, lalu sistem mengarahkannya ke `/booking?lapanganId=X`.
4. **Pengisian Form Booking**:
   - Di halaman `/booking`, pelanggan memilih tanggal sewa, jam mulai (misal: 08:00), dan jam selesai (misal: 10:00).
   - Sistem secara otomatis memvalidasi jadwal agar tidak bentrok dengan booking pelanggan lain atau slot yang diblokir admin.
   - Sistem menghitung total tagihan (Durasi x Harga per jam).
   - Pelanggan menekan tombol **Buat Pesanan**.
5. **Pembayaran & Upload Resi Transfer**:
   - Pelanggan otomatis dialihkan ke halaman **Riwayat Booking** (`/riwayat`). Status transaksi adalah `Pending` dan status pembayaran `Belum Bayar`.
   - Pelanggan melakukan transfer ke rekening pengelola Sukatani Tenis.
   - Pelanggan mengklik tombol **Upload Bukti Bayar**, memilih file resi, dan menekan **Simpan**.
   - Pelanggan juga dapat mengklik tombol **Konfirmasi via WhatsApp** untuk mengirim pesan otomatis ke admin.

B. ALUR SCENARIO ADMIN (ADMIN OPERATIONAL FLOW):
1. **Autentikasi Admin**: Admin mengakses `/login`, menginputkan email & password akun admin. Sistem mengenali role `admin` dan mengarahkannya ke halaman `/admin`.
2. **Pemantauan Dashboard**: Admin melihat statistik pada `/admin` (misal: Pesanan Hari Ini, Total Pendapatan, dan Jumlah User).
3. **Validasi & Konfirmasi Pesanan**:
   - Admin membuka menu **Pemesanan** (`/admin/pemesanan`).
   - Admin melihat daftar transaksi dengan badge status `Pending`.
   - Admin mengklik ikon **Bukti Bayar** untuk memeriksa foto resi transfer pelanggan.
   - Apabila dana sudah masuk, Admin mengklik tombol **Konfirmasi**. Status transaksi berubah menjadi `Dikonfirmasi` dan status pembayaran menjadi `Sudah Bayar`.
4. **Manajemen Jadwal (Slot Blokir)**:
   - Jika ada perawatan lapangan atau turnamen internal, Admin membuka menu **Kelola Jadwal** (`/admin/jadwal`).
   - Admin mengklik **Tambah Slot Blokir**, memilih lapangan, tanggal, jam mulai, jam selesai, serta mengisi alasan (contoh: "Perbaikan Net & Garis").
   - Setelah disimpan, slot jam tersebut tidak akan bisa dipilih oleh pelanggan pada halaman `/booking`.
5. **Kelola Lapangan & User**:
   - Admin dapat menambah atau mengubah tarif lapangan pada menu **Kelola Lapangan** (`/admin/lapangan`).
   - Admin dapat mengaktifkan/menonaktifkan akun user pada menu **Kelola User** (`/admin/users`).
6. **Pencetakan Laporan Periodik**:
   - Pada akhir bulan, Admin membuka menu **Laporan** (`/admin/laporan`).
   - Admin memilih bulan dan tahun, lalu menekan tombol **Cetak Laporan** untuk mengunduh rekapitulasi data pendapatan dalam bentuk PDF / Print.
