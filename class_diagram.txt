3.2.1.3 Perancangan Class Diagram

      Class diagram (diagram kelas) menggambarkan struktur sistem dari segi pendefinisian kelas-kelas yang akan dibuat untuk membangun sistem. Setiap kelas memiliki atribut (properti/data) dan method (fungsi/operasi) yang saling berhubungan satu sama lain melalui relasi tertentu. 

      Dalam sistem penyewaan Lapangan Tenis Sukatani, perancangan class diagram terbagi menjadi kelas entitas utama (database model) serta kelas pengontrol (controllers & services) yang menangani logika bisnis sistem. Penjelasan kelas-kelas utama dalam sistem adalah sebagai berikut:

1. Class User: Menyimpan informasi pengguna sistem, baik pelanggan (role: user) maupun pengelola (role: admin). Memiliki fungsi untuk autentikasi dan kelola profil.
2. Class Lapangan: Menyimpan data arena/lapangan tenis beserta detail harga, fasilitas, foto, serta jam operasional.
3. Class Booking: Menyimpan seluruh transaksi pemesanan lapangan oleh pelanggan, durasi, total biaya, status verifikasi, dan status pembayaran.
4. Class SlotBlokir: Menyimpan data slot waktu atau tanggal tertentu pada lapangan yang diblokir oleh admin (misalnya untuk keperluan perawatan/maintenance atau turnamen).
5. Class Controllers & Services: Merupakan kelas pengolah logika bisnis seperti AuthController, UserController, LapanganController, BookingController, JadwalController, ReportController, serta WhatsAppService untuk notifikasi.

@startuml
skinparam classAttributeIconSize 0

package "Models" {
  class User {
    - id : int
    - nama : String
    - email : String
    - password : String
    - role : String
  }

  class Lapangan {
    - id : int
    - nama : String
    - harga_per_jam : int
    - status : String
  }

  class Booking {
    - id : int
    - user_id : int
    - lapangan_id : int
    - status : String
    - status_pembayaran : String
  }

  class SlotBlokir {
    - id : int
    - lapangan_id : int
    - tanggal : Date
  }
}

package "Controllers" {
  class AuthController {
    + register(req, res)
    + login(req, res)
    + getProfile(req, res)
  }

  class UserController {
    + getAllUsers(req, res)
    + toggleUserStatus(req, res)
    + deleteUser(req, res)
  }

  class LapanganController {
    + getAllLapangan(req, res)
    + getLapanganById(req, res)
    + createLapangan(req, res)
    + updateLapangan(req, res)
    + deleteLapangan(req, res)
  }

  class BookingController {
    + createBooking(req, res)
    + getUserBookings(req, res)
    + getAllBookings(req, res)
    + confirmPayment(req, res)
    + cancelBooking(req, res)
  }

  class JadwalController {
    + getJadwalByTanggal(req, res)
    + createSlotBlokir(req, res)
    + deleteSlotBlokir(req, res)
  }

  class ReportController {
    + getMonthlyReport(req, res)
    + exportReportPDF(req, res)
  }
}

package "Services & Middleware" {
  class AuthMiddleware {
    + verifyToken(req, res, next)
    + checkAdmin(req, res, next)
  }

  class WhatsAppService {
    + sendBookingConfirmation(phone, bookingData)
    + sendStatusUpdateNotification(phone, status)
  }
}
