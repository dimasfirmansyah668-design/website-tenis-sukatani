2. PENJELASAN STRUKTUR NAVIGASI ADMIN (NARASI PARAGRAF)
----------------------------------------------------------------------------------

      Struktur Navigasi Admin Gambar 3.14 terdapat susunan menu dan halaman yang dirancang untuk memudahkan pengelola dalam mengontrol dan mengoperasikan sistem. Di dalamnya, admin terlebih dahulu harus melakukan login untuk dapat masuk ke panel dashboard utama. Admin yang sudah melakukan login bisa mengakses menu dashboard admin, kelola pemesanan, kelola lapangan, kelola jadwal, kelola user, dan laporan transaksi. Pada menu kelola pemesanan admin dapat melihat detail pesanan, memvalidasi bukti pembayaran, serta mengonfirmasi atau membatalkan pesanan. Pada menu kelola lapangan admin dapat menambah lapangan, mengedit data lapangan, dan menghapus lapangan. Pada menu kelola jadwal admin dapat menambah slot blokir dan menghapus slot blokir untuk perawatan lapangan. Pada menu kelola user admin dapat mengubah status keaktifan user dan menghapus akun user. Pada menu laporan transaksi admin dapat memilih filter periode bulan dan mencetak laporan pendapatan.

3. PETA ROUTING & AKSES FITUR NAVIGASI ADMIN
----------------------------------------------------------------------------------

+--------------------+--------------------+---------------------------------------+
| Route Path         | Nama Halaman       | Fitur & Akses Sub-Menu                |
+--------------------+--------------------+---------------------------------------+
| /login             | Login Admin        | Autentikasi akun admin                |
| /admin             | Dashboard Admin    | Ringkasan statistik & total pesanan   |
| /admin/pemesanan   | Kelola Pemesanan   | Detail pesanan, validasi bukti bayar, |
|                    |                    | konfirmasi & pembatalan               |
| /admin/lapangan    | Kelola Lapangan    | Tambah, edit, hapus, & status aktif   |
| /admin/jadwal      | Kelola Jadwal      | Tambah & hapus slot blokir jadwal     |
| /admin/users       | Kelola User        | Status keaktifan (aktif/blokir) &     |
|                    |                    | hapus user                            |
| /admin/laporan     | Laporan Transaksi  | Filter periode bulan & cetak PDF/print|
+--------------------+--------------------+---------------------------------------+
